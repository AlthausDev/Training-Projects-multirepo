# Training Projects Multirepo

Colección de ejercicios, pruebas de concepto y pequeños proyectos realizados durante formación y práctica técnica.

El repositorio agrupa ejemplos por tecnología para conservarlos como referencia y laboratorio personal, sin pretender que todos los subproyectos formen una única aplicación.

## Contenido

- `Android-Kotlin/` — ejercicios y aplicaciones Android con Kotlin.
- `Angular/` — prácticas de frontend con Angular.
- `Blazor/` — ejemplos y ejercicios con Blazor/.NET.
- `C#-GUI-Frameworks/` — pruebas con frameworks de interfaz en C#.
- `Java/` — ejercicios y proyectos Java.
- `Python/` — scripts y prácticas con Python.

Algunos subproyectos pueden conservar versiones antiguas de dependencias porque forman parte del estado histórico del ejercicio. Las alertas de seguridad relevantes se corrigen cuando afectan al código conservado en la rama principal.

## Propósito

Este repositorio funciona principalmente como archivo técnico y zona de experimentación: comparar enfoques, recuperar ejemplos concretos y conservar progresión entre tecnologías.
